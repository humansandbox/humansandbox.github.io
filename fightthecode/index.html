    What you are looking at

    Each task is a short C# method stored in the StrictDev task database. The ORANGE TESTABLE engine reads the code statically, enumerates every branch, and reports a verdict. ORANGE means the method is loop-free and finitely branched after analysis, so its full result table can be derived without writing tests by hand. Coverage is the line coverage measured when the derived tests are run.

    Task names and code comments are in Japanese, as recorded.
