What this site is

This site publishes measured A/B cost data for a question most of the industry argues about with opinions: what does test-first ceremony actually cost when the implementer is an LLM coding agent? Two arms are run against identical task specifications under equalized verification obligations (100% line coverage, mutation testing):

  • RGR (branch-grained) — textbook red→green discipline, one failing test per design decision, enforced by protocol
  • Direct-to-GREEN — implementation and tests generated together, incidental failures repaired

Every run records its full turn ledger: effective tokens, wall clock, test-run events (planned red / accidental red / green / vacuous red), oracle-adjudication turns, coverage, mutation scores, and per-member outcomes. The viewer reads a static snapshot of the evidence database — no backend required.

UI is in English. Task specifications and some run annotations are in Japanese (primary data is preserved as recorded).
